The first release of NightFire Online: 007: NightFire's PC port, played online. It is built on Harry's
[nightfire-recomp](https://github.com/hk21x/nightfire-recomp) (the port itself: the recompiled game, its graphics,
controls, PC settings and achievements) and adds online play on top of it.

## Online multiplayer

The console's own split-screen matches, with each player on their own PC: its modes, maps and bots, up to 10 players
and bots in all. Every PC runs the same match from everyone's input (lockstep), so no game state is sent and nobody
has an advantage from being the host.

## Campaign co-op

- Up to 4 players through the on-foot missions, each with their own view, controller and name tag. A downed player
  respawns beside a teammate; only the last one down fails the mission.
- The driving missions with a second player on the car's guns, torpedoes and turrets.

## Finding and hosting a game

- **Server Browser** (F1): games on your network and on the internet list, with ping, players and map.
- **Join codes and a relay server**: a host gets a short code to share, no port needs forwarding, and no player
  sees another's IP address.
- **Hosting** (F1, Online): who can join (anyone, or only those with the code or password), a player who drops
  can take their seat back, the host's QUIT can take everyone back to the menus (Everyone quits with the host, on
  by default), and **Restart the session for everyone** for a session that is stuck.

Every player needs this same release.

## Getting it

Download **NightFireOnlineLauncher.exe** below, put it in a folder of its own and run it, choose your disc image or
the folder with the disc's files, and press **Get the game ready**. It works in a `NightFireOnline` folder beside
itself, so it does not touch an install of Harry's port.

| File | What it is |
|---|---|
| `NightFireOnlineLauncher.exe` | **The only file to download by hand.** It fetches the rest itself. |
| `NightFire-package.zip` | The runtime and the compiler, for both discs, and no game code. The launcher fetches it. |
| `NightFire-package.zip.json` | The size and SHA-256 the launcher checks the download against. |

No game files are included. You need your own copy of the game (the European PAL or the USA release).

Problems: open an [issue](https://github.com/billfoldes/nightfire-online/issues) with the game's log from
`NightFireOnline\play\logs` (and `NightFireOnline\launcher.log` if the launcher failed).
