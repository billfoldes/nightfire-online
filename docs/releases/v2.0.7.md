Quicker games by join code, and hosting by IP without opening ports by hand.

- **Join codes connect directly when they can.** A game by join code still starts through the relay, but then the
  host and each joiner try to reach each other directly. When that works, the match's packets go straight between
  them, so the relay's distance is no longer added to the delay. If the direct path stops, the game goes back to the
  relay by itself within about two seconds. The setting is **Connect directly when possible** (F1, Online, under
  Servers), on by default, and it is used only when the host and that player both have it on. With a direct
  connection, each PC knows the other's IP address, though it is never shown; turn it off to keep yours from the
  other players.
- **The game opens its port on your router.** A host that players reach by its IP address now asks the router
  (UPnP) to forward its UDP port, so players on the internet can join without port forwarding set up by hand. The
  setting is **Open my port on the router (UPnP)**, under Advanced, on by default. Routers with UPnP switched off
  still need the port forwarded by hand.
- **Self-hosting:** the README now points at how to run your own server list or relay.

Every player needs this same release. Already have the launcher? Open **NightFireOnlineLauncher.exe** and press
**Update**. New players: download **NightFireOnlineLauncher.exe** below, choose your disc and press
**Get the game ready**. See the [v2.0.0 notes](https://github.com/billfoldes/nightfire-online/releases/tag/v2.0.0)
for everything in NightFire Online.

| File | What it is |
|---|---|
| `NightFireOnlineLauncher.exe` | **The only file to download by hand.** It fetches the rest itself. |
| `NightFire-package.zip` | The runtime and the compiler, for both discs, and no game code. The launcher fetches it. |
| `NightFire-package.zip.json` | The size and SHA-256 the launcher checks the download against. |

No game files are included. You need your own copy of the game (the European PAL or the USA release).
