Two co-op fixes.

- **No crash after changing character mid-level.** Picking another character in F1 during a co-op level crashed
  every machine a few seconds later. A new character is now yours from the next level (in a match, the next match),
  as the setting says.
- **No respawning under the level.** A co-op player who died came back a step beside their teammate, which could be
  past a ledge or behind a wall. They now come back on the teammate's own spot and can walk through them until the
  two have stepped apart.

Every player needs this same release. Already have the launcher? Open **NightFireOnlineLauncher.exe** and press
**Update**. New players: download **NightFireOnlineLauncher.exe** below, choose your disc and press
**Get the game ready**. See the [v2.0.0 notes](https://github.com/billfoldes/nightfire-online/releases/tag/v2.0.0)
for everything in NightFire Online.

| File | What it is |
|---|---|
| `NightFireOnlineLauncher.exe` | **The only file to download by hand.** It fetches the rest itself. |
| `NightFire-package.zip` | The runtime and the compiler, for both discs, and no game code. The launcher fetches it. |
| `NightFire-package.zip.json` | The size and SHA-256 the launcher checks the download against. |

No game files are included. You need your own copy of the game (the European PAL or the USA release).
