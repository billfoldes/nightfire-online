Keyboard controls you can change by what they do.

- **F1, Controls, Keyboard** lists each action with its keys, on foot ("Move forward", "Fire", "Crouch", "Jump",
  "Action, reload" ...) and driving ("Accelerate", "Handbrake", "Camera", "Look back" ...), and each key changes
  right there: press its box, then the new key or mouse button (Escape clears it). The table below it, now
  **Controller**, still maps each console input to its keys and a controller button.
- Unlocking what the cheat codes give is **Unlock every reward** in F1's game options (since 2.0.8).
